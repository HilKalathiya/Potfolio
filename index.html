How to read the graphs

Every system, drawn as the agent graph it runs on.

The graph beside this text is the system running this page. Every project below is drawn with the same parts, wired the way its code is: real file names, labelled edges, and the loop each agent actually runs.

  • AgentPlans, calls tools and picks the next step.
  • ModelAn LLM, a classifier or a forecaster.
  • ToolA function an agent can call, named as it is in the code.
  • MemoryA database, an index or a vector store.
  • GuardrailA limit the agent cannot break, like a call budget.
  • BranchA conditional edge: the graph picks the next step, as LangGraph does.
  • PersonApproves before anything leaves the system.
  • DashedPlanned, not built yet. Nothing pretends otherwise.
  • EdgeLabelled with what travels on it. Blue is an agent working, amber waits on a person.

01Internship at HNNOIX · May–Jul 2026 shipped

MDT AI Copilot

An agentic RAG copilot for 5G network analytics. Ask it a question in plain language and it scans the network's own measurements, reads its documentation and C source, and cites every number.

Pattern
LangGraph create_react_agent: the agent calls tools through a ToolNode and loops until it has no tool calls left
Model
Cohere Command R+ for tool calling, embed-v4.0 for search
Tools
query_reports run_anomaly_scan get_cell_summary suggest_threshold retrieve_docs
Guardrails
8 tool calls per question, tool output cut at 4,000 characters, numbers must be cited
Result
80%+ recall on injected coverage holes; the forecaster beats a naive baseline

02Team project · Feb–May 2026 live demo

OpenEnv data-cleaning agent

A reinforcement-learning environment where an agent cleans a messy table one typed action at a time, scored against a hidden clean copy. A PPO policy and a zero-shot Llama 3.1 8B compete on the same actions.

Pattern
RL environment served over FastAPI and WebSocket, with LLM and PPO agents
Actions
9 typed actions, validated by Pydantic before they touch the data
Guardrails
Invalid actions are not applied; potential-based reward cannot be farmed by looping
Hard task
PPO 0.967 · rule-based 0.968 · Llama 3.1 8B 0.838 · doing nothing 0.608
Shipped
Docker image on Hugging Face Spaces; PPO runs on NumPy alone

04System design · Sep 2026 design, simulation-tested

eCTD Audit Platform

A design for assembling the manufacturing section of a drug-approval filing. Every number traces back to lab data, code computes it, and a person signs each section. The model drafts, and never decides.

Pattern
A mostly fixed LangGraph state machine, not free-roaming agents
Integrations
One MCP server per system: LIMS Empower SAP Veeva Vault
Rule
The model never types a digit; a validated statistics library computes every number
People
Reader disagreements go to review, and a person signs every section
Simulated
0 wrong values stored out of 9,600; 194 sent to a person

Finds and grades Crohn's lesions in capsule-endoscopy frames, offline on an ordinary CPU, and holds up at hospitals it never trained on. A research prototype, not a medical device.

New hospital

Explains
